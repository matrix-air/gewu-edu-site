同一节课，三种人各要一件东西——现有产品只给了一半

学生要「听得懂」，家长要「看得见的证据」，老师要「省时的演示」。三件事错位，所以一份内容必须一鱼三吃。

听得懂 ≠ 会做题

最深的痛点不是不会算，是物理情景脑补不出来——"传送带上的板块到底怎么动？磁场里粒子的轨迹长什么样？"讲题视频讲完这一道，下一道换个场景还是不会。

画像 B · 家长（付款者）

付的是焦虑，要的是证据

焦虑 × 证据 = 预算；有焦虑没证据 = 流失。万元学习机卖点趋同，家长越来越难判断"钱花得值不值"。心理价位：学习机 2,000–4,000 元，年课 0.8–4 万。估

画像 C · 老师（影响者）

抽象概念要能当场演示

备课省时、课堂演示有效果、学情可见、合规无风险。老师不是付款主体，但是最好的获客钩子——场景交互页天生就是课堂投影课件。

所以产品的形态是一份内容、三种交付：同一个场景页，是学生「看得懂的思路」、是家长「可展示的进步证据」、是老师「现成的演示课件」。

主轴一 · 情境锚定律

常识 → 交互 → 公式：把教学顺序倒过来

传统教学从公式出发，学生背下了却不懂。格物从现象出发：先问一个学生答得上的生活问题，再让他拖着参数自己发现规律，最后公式只是把已经看懂的事记成账。

01 · 锚

先找一个他天天见的原型

板块模型 = 行李箱过扶梯；电磁感应 = 强磁掉进铜管会变慢。场景不是包装，是认知的落脚点——先让他有话说。

02 · 玩

拖参数，自己撞出规律

不是看预制动画，是拖一下、画面立刻变。把 α 拖到接近共线，绳子拉力瞬间发散的震撼，比背一句"sin 在分母"管用得多。

03 · 落

公式只是记账

规律已经被看见了，公式负责把它写成可迁移的语言。这时学生看到的不再是符号，是刚刚玩过的那个现象。

主轴二 · 全域图式律

不做"搜一题讲一题"，一个领域一次收齐

底盘 · 教材内容层

覆盖门不再只查到「章」——已经查到每一节

「一个领域一次收齐」不能靠嘴说。人教 2019 全 16 册逐节拆成可核条目，每条都标出它在高考卷上的接口——这才是「一格都不落」的可验证含义。

01 · 双层门

纲要不漏章，内容不漏节

第一道门比对大纲（65 章 + 254 条节级条目），第二道门比对教材内容层（册数 + 真实正文节数 + 来源，四重校验）。任一条缺失即退出码非 0，自动回炉。

02 · 逐节骨架

每节都用同一把尺子

定义对象 → 公式结论 → 方法技能 → 实验要点 → 教材栏目线索 → 高考接口。各科按学科习惯命名其中几栏，但骨架位置一致，机器才数得清。

03 · 可追溯

每节直接挂到考纲考点

每节末栏写清它对应大纲哪一章、哪一考点、什么权重。想查某个考点「教材里在哪讲、讲到多深」，顺接口就能翻回去——这是给内容生产线用的地图。

常见问题

你可能想问的

这和搜题 App / 学习机有什么区别？
搜题 App 是"一题一讲"，用完就散——学生永远不知道自己漏了哪一块。学习机的 AI 讲题仍然是"我讲你听"。格物做的是两件他们没做透的事：把解题思路还原成能动手拖的生活场景，以及把一个领域的知识点一次收齐并机器验完备。
会不会又是"看动画"？
不会。动画是播给你看的，格物的画面是等你来拖的。页面上每一个演示——绳子的角度、传送带的带速、磁场的宽度——都是可调参数，拖一下物理量立刻重算。你现在就可以在上面那块演示台上试。
知识点的完备性怎么保证？不是你说齐就齐。
用两道机器门兜底。第一道比对大纲：三科 65 章的"章 + 节"清单内嵌在校验脚本里，逐条归一化匹配，任何缺失条目直接退出码非 0。第二道比对教材内容层：人教 2019 全 16 册的册数、真实正文节数（数学 73 / 物理 125 / 化学 60）、以及每册必备的来源区，同样一缺即退出码非 0。漏了就自动回炉，当前状态：两道门全绿。
那个"教材内容层"是什么？和教材原文什么关系？
是教材要点整理，不是原文复制。按人教 2019 教材目录逐节拆条目，每节固定六栏骨架（定义对象 / 公式结论 / 方法技能 / 实验要点 / 教材栏目线索 / 高考接口，各科按学科习惯命名其中几栏），每册带可核来源链接。粒度到"每节的定义与公式"，还没到"逐公式证明、逐例题"。它的用途是当内容生产线的底盘——哪个考点该配场景课、哪节是空白，看这张表就知道。
物理数值会不会写错？错了就是信誉事故。
每页必须过"解析数值一致"校验才允许上线。已上线的 3 道真题页与官方解析数值一致；其中 2023 压轴第 2 问的临界磁场宽度，我们按动量定理重推为 W* = 2.00 L，并用该链路验算产热恰等于官方答案。错误的页面不上线。
现在能买到吗？多少钱？
还买不到。现在是 P0 原型阶段，正在做力学域的内容和对照实验，目标是先拿到一组科学的对拍数据再谈商业化。定价预期对标家长心理价位（学习机 2,000–4,000 元带），但形态与定价都未定，一切以验证结果为准。
